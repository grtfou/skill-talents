符文之路：第一次玩就上手

這是一張「英文闖關地圖」。每個小圖案，都是一件可以學的事。

先學習，再幫自己加一點。1 點就是 1 小時。

1. 先把程式打開

請大人幫你下載適合電腦的壓縮檔。第一次開啟時，請大人陪你一起做。

我用 Windows 10

  1. 找到檔名有 win-x64.zip 的檔案。
  2. 用滑鼠右鍵點它，選「解壓縮全部」。
  3. 打開解壓縮好的資料夾。
  4. 找到 SkillTalents.exe，點兩下。

不要只把 exe 拿出來。旁邊的檔案也要留在一起，程式才會正常開啟。

我用 Mac Intel

  1. 找到檔名有 mac-x64.zip 的檔案，點兩下解壓縮。
  2. 找到「符文之路.app」。電腦可能只顯示「符文之路」，這也一樣。
  3. 把它拖到「應用程式」資料夾。
  4. 以後就到「應用程式」，點兩下「符文之路」。

這一版適合 Windows 10 的 64 位元電腦，以及 macOS 12 以上的 Intel Mac。看不懂這些名稱沒有關係，請大人幫你選就好。

程式已經把需要的工具放進去了。你不用安裝 Python 或 Node.js，也不用開終端機。

如果電腦出現「無法確認開發者」或安全提醒，先停下來，請大人確認檔案來源。本次提供的版本還沒有發行者簽章，所以可能需要大人協助確認；不要關掉整台電腦的安全保護。

2. 先找一個想學的技能

打開後，先選「符文基礎」。

如果你是第一次學英文，可以從「初始字母之印」開始。它的意思是：學會 26 個大寫英文字母。

點一下技能的名字，看看右邊的「學習內容」。你會知道今天要學什麼。視窗比較小時，說明會出現在技能樹下方。

「Eng-TOEIC」是這張英文地圖的名字。你可以慢慢走，不用急著一次走完。

3. 學完一小時，幫自己加一點

  1. 先用課本、影片或老師準備的材料學習。
  2. 學滿一小時後，點一下技能的圖案。
  3. 也可以按說明旁邊的「＋ 投入 1 小時」。

例如看到 3 / 20：

  • 前面的 3：你已經記錄了 3 小時。
  • 後面的 20：這個技能先安排 20 小時練習。

你不用連續坐著學一小時。可以先學 20 分鐘，休息後再學；累計到 60 分鐘，再加一點。零碎的分鐘可以先記在紙上。

只要點一次就加一點，不用點兩下。

4. 灰色的技能，為什麼不能加點？

有些技能要先學會前面的內容，才會打開。

例如：「初始字母之印」記滿 8 / 8 後，就能開始「雙生字母契約」，學小寫字母。

灰色技能也可以點名字查看說明。找到「先備技能」，就知道要先完成哪一個。點先備技能的名字，會帶你找到它。

如果列出兩個先備技能，就要兩個都記滿。不同路線也可能有共同的基礎。

5. 點錯了怎麼辦？

別擔心！按技能下面的「−」，或說明旁邊的「收回 1 小時」，就能減掉一點。

如果不能減，先看看後面的技能是不是已經加過點。

例如：你已經開始學小寫字母，想收回大寫字母的點數，就要先把小寫字母的點數收回，再收回大寫字母。這樣才不會把前後順序弄亂。

6. 今天學完了，可以直接關掉嗎？

可以。沒有出現儲存錯誤時，程式會在你加點或減點後自動記住。

下次用這台電腦、同一個使用者帳號開啟程式，就能接著用。不用每天重新開始。

如果畫面說「無法儲存」，先不要關掉，請大人幫你按「匯出旅程」，把紀錄另存成檔案。

7. 做一份備份，就像把存檔放進書包

建議每週做一次。換電腦、更新程式或重置前，也先做一次。

  1. 按「匯出旅程」。
  2. 如果跳出存檔視窗，選「文件」或你找得到的資料夾，再按「儲存」。
  3. 你會得到一個名字有 Eng-TOEIC、副檔名是 .json 的檔案。
  4. 把它留好。不用打開，也不要改裡面的內容。

想把紀錄帶到另一台電腦：

  1. 把這個備份檔複製到另一台電腦。
  2. 在那台電腦打開「符文之路」。
  3. 按「匯入備份」，選剛才的檔案。
  4. 看看顯示的時數對不對，再按「確認匯入」。

匯入會取代那台電腦原本的紀錄。想保留原本的紀錄，就先匯出另一份備份。

以前用網頁版的紀錄也可以這樣搬進程式；它不會自己搬過來。

8. 我想全部重新開始

  1. 先「匯出旅程」，留一份備份。
  2. 按「重置所有點數」。
  3. 如果確定要全部歸零，再按「確認全部歸零」。

不想重來就按「保留進度」。沒有備份時，清掉的點數不能找回來。

9. 我找不到要學的內容

在「搜尋全部技能」輸入「字母」、「假設」或「聽力」，就能找。

技能很多時，可以按搜尋旁邊的按鈕，換成一列一列的清單。字太小時，桌面版上方的「檢視」可以放大文字。

想再看一次這份說明，可以按「如何遊玩」裡的「完整操作說明」；桌面版上方的「說明」也找得到。

記住三件事就好

  • 先學習，再加點。 點數是在記錄練習，不是按了就學會。
  • 點錯可以退。 不用因為點錯就整張地圖重來。
  • 記得做備份。 程式會記住這台電腦的進度，備份可以帶去另一台。

記滿時數後，也做做「自我檢核」，看看自己是不是真的懂了。還不熟就再練習，不用急著往前。

這張地圖的目標是 TOEIC 聽力與閱讀 900 分以上；點滿地圖不等於考到 900 分。每次學一點、慢慢進步，就很好。
