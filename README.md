# 符文之路｜把學習變成一場冒險

這是一張英文闖關地圖。你每學習一小時，就能幫一個技能加一點。

**先學習，再加點；點錯可以退，下次開啟還能接著用。**

## 第一次開啟

請先把下載的 ZIP 檔案解壓縮。

- **Windows 10（64 位元）：** 打開解壓縮好的資料夾，點兩下 `SkillTalents.exe`。其他檔案要留在旁邊，不要只把 exe 拿走。
- **Mac Intel（macOS 12 以上）：** 把「符文之路.app」拖到「應用程式」，再點兩下開啟。

使用打包好的桌面版，**不用安裝 Python、Node.js 或其他工具**，也不用開終端機。沒有網路仍可使用。

目前提供未簽章版本。第一次若有安全提醒，請大人協助確認檔案來源與系統提示，不要關閉整台電腦的安全保護。詳細平台、打包與發佈狀態見[桌面版說明](docs/桌面版與打包.md)。

## 每天只要四步

1. **選技能。** 先到「符文基礎」，從「初始字母之印」開始。
2. **看看要學什麼。** 點技能的名字，讀「學習內容」。
3. **學習後記錄。** 學滿一小時，點一次圖案或「＋ 投入 1 小時」。
4. **下次繼續。** 程式會記在這台電腦。每週記得按「匯出旅程」，另存一份備份。

例如 **3 / 20**，就是已記錄 3 小時，這個技能先安排 20 小時練習。

點錯可以按「−」。灰色技能要先完成「先備技能」才能加點，仍然可以點名字查看說明。

## 我需要更多幫忙

看[小學生也看得懂的完整操作說明](docs/操作說明.md)，裡面有：

- Windows 與 Mac 怎麼開啟。
- 怎麼加點、退點、解鎖下一個技能。
- 怎麼備份、換電腦、搬入舊網頁版紀錄。
- 怎麼全部重新開始，以及出現儲存錯誤時怎麼辦。

程式裡的「如何遊玩 → 完整操作說明」也能看，不用連網。

## 給家長與老師

第一張地圖叫 **Eng-TOEIC**，目標是 TOEIC 聽力與閱讀 900 分以上。它有六條路線、168 個技能，每項 8–20 小時。

全樹 2,758 小時是給零基礎、學得較慢者的保守規劃，包含練習、複習和檢討；不是研究證實的平均，也不是每個人都必須學滿的時數。內容和時數仍需教師與試用者校準。

這是學習進度工具，教材與題目需自行準備。點滿代表記錄完成，**不等於已學會或考到 900 分**。請搭配「自我檢核」。

進度不會自動搬到別台電腦，也不會從舊網頁版自動搬入。請先匯出，再到新的程式匯入。刪除程式資料或更換電腦使用者帳號前，也先備份。
