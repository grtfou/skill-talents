# 符文之路｜學習天賦樹

把學習時數變成可投入、可收回的天賦點。第一套職業為 **Eng-TOEIC**，目標是 TOEIC 聽力與閱讀 900 分以上；日語、素描及英語交流職業保留擴充方式。

目前提供可操作的本機初版、完整架構與計畫書，以及 **168 項技能／168 個原創 SVG 徽章**。不需帳號、資料庫、套件安裝或雲端服務。

## 開啟方式

需要 Python 3.9 以上。macOS 可雙擊專案內的 **「開啟天賦樹.command」**。若系統限制雙擊執行，請在終端機切到這個資料夾後執行：

```sh
python3 start.py
```

程式會自動開啟 <http://127.0.0.1:4173>。保留終端機視窗；按 `Ctrl+C` 關閉。僅綁定本機，不開放區域網路。請固定使用此網址和同一個瀏覽器，才能延續相同儲存空間。

Windows 可執行 `py start.py`。不需 Node.js 即可使用；只有開發測試需要 Node.js 18 以上。

若 4173 被其他程式占用，可執行 `python3 start.py --port 4174`；不同連接埠屬於不同儲存來源，切換前先匯出進度。不支援直接雙擊 HTML（瀏覽器會限制模組載入）。

## 怎麼使用

1. 選擇左側路線，點技能名稱查看學習內容、先備與自我檢核。
2. 實際學一小時後，點技能圖示或「投入 1 小時」。`3/20` 代表已記錄 3 小時，該技能規劃 20 小時。
3. 點錯可按「−」收回；若後續技能已投入，先由後往前退點。
4. 先備技能全部滿點後，解鎖下一項。不同主題可平行學習。
5. 進度自動存在瀏覽器；定期「匯出旅程」下載 JSON，需要時再匯入。
6. 「重置所有點數」經確認後歸零；重置前可匯出備份。

灰色技能仍能點名稱查看說明。搜尋會跨六條路線查找實際主題、奇幻名稱與說明；右上按鈕可切換清單，手機也可操作。

## 時數與教材

全樹規劃 **2,758 小時**，每項 8–20 小時，包含新學、練習、複習及檢討。這是為零基礎且學得較慢者制定的保守預算，**不是研究證實的平均時數，也不是分數保證**。各技能的時數仍需由教師及試用者校準。

這是一套學習進度與路線工具，初版不附完整教材、音檔、題庫、計時器或官方成績換算。自我檢核是文字指引，不是系統自動測驗。已有學習經驗者可依實際既有投入手動記點；目前沒有批次跳過先備功能。

所有前端資產均在本機，不連線外部字型、分析服務或 API。無網際網路時仍可使用，但本機伺服器必須保持開啟。瀏覽器清除資料、無痕模式或換裝置不會自動轉移進度，請使用 JSON 備份。

## 開發與擴充

```sh
# 規則與資料驗證（無第三方依賴）
node --test

# 調整課程來源後，重建資料、圖示與技能目錄
python3 scripts/build_curriculum.py
```

來源在 `scripts/build_curriculum.py`；產生資料在 `app/data/curriculum.js`。課程內容使用繁體中文，保留實際英語學習用語；程式識別碼使用英文。所有圖示為本專案程式產生的 SVG，不使用遊戲原有素材。

如果未來建立 Git commit 或 PR，commit 訊息與 PR 標題用英文；PR 內文與所有專案文件用繁體中文。
