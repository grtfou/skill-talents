## 語言教學與記憶依據

- [Council of Europe：CEFR Companion Volume（2020）](https://rm.coe.int/cefr-companion-volume-with-new-descriptors-2020/16809ea0d4) 與[行動導向教學](https://www.coe.int/en/web/common-european-framework-reference-languages/the-action-oriented-approach)：以有目的的任務涵蓋接收、產出、互動與中介。本專案據此從介紹、約時間、轉述、交接逐步增加任務複雜度，不只練選擇題。
- [Council of Europe：Phonological competence](https://www.coe.int/en/web/common-european-framework-reference-languages/phonological-competence)：發音編排重視可理解度、重音與語調。因此 KK／IPA 作查音工具，先聽說與錄音回饋，不把背完整音標或消除口音作為開口門檻。
- [Nation：The Four Strands（2007，作者所屬大學提供）](https://www.wgtn.ac.nz/lals/resources/paul-nations-resources/paul-nations-publications/publications/documents/2007-Four-strands.pdf)：建議平衡意義導向輸入、輸出、語言形式與流暢發展。本專案用每週安排與技能內活動實作此原則；四類活動不等同四種技能，也不宣稱技能節點數或預算已達等比例。
- [Kim & Webb（2022）：The Effects of Spaced Practice on Second Language Learning](https://onlinelibrary.wiley.com/doi/full/10.1111/lang.12479)：第二語言間隔練習的統合分析支持分散練習，但效果受任務與間隔等因素影響。本專案把 v31 放到第一週，以跨日檢核取代同日反覆熟讀作為唯一依據。
- [The Learning Scientists：Retrieval Practice](https://www.learningscientists.org/retrieval-practice) 與[Spaced Practice](https://www.learningscientists.org/spaced-practice)：先遮住答案嘗試回想，再核對回饋，並分散於不同日。技能中安排情境提示說詞、聽後重述、獨立寫句與延後換材料檢核。

供在職成人試用的安排：每天可拆成 2–3 段各 10–15 分鐘，先回想舊內容，再做少量新材料與自主表達；每週涵蓋聽說讀寫。複習可試隔天、3 天、7 天、14 天，忘記就縮短，熟悉就拉長。這些分鐘數、間隔與檢核量是編輯示例，**不是研究規定的唯一最佳排程**。先分開建立意思，再交錯容易混淆的形式；精聽精讀與大多能懂的泛聽泛讀並行，跟讀之後還要撤去提示自主說寫。

檢核以未見材料、可理解的訊息與具體回饋為主。寫作「字數」均以英文單字數計；字數與時長是練習目標，可按實際程度調整。教材、音檔、同伴或教師回饋需自行安排；系統只記錄投入，沒有自動執行複習、判定能力或提供對話評分。

部分 ID 的用途、先備已重新設計，例如 g26/g27 由低頻假設句改為方案協商與意見段落。為避免舊時數被誤認成新能力，課程版本由 `2026.10.1` 更新為 `2026.10.2`，資料結構版本不變。現有儲存機制會拒絕直接載入舊課程版本，讀取失敗時保留原始資料；本次沒有加入轉移程式。已有進度者應先在舊版匯出並保存備份，再以新版作品檢核決定後續記錄，不要只改備份版本字串。

## 測驗範圍

[ETS：TOEIC Listening and Reading 測驗介紹](https://www.ets.org/toeic/about/listening-reading.html) 列出傳統測驗的兩個部分：聽力 100 題／約 45 分鐘，閱讀 100 題／75 分鐘。聽力含照片、問答、對話與獨白；閱讀含句子填空、段落填空與閱讀理解。本課程採這套題型範圍。

[ETS：應試手冊](https://www.ets.org/content/dam/ets-org/fr/pdfs/toeic/toeic-listening-reading-test.pdf) 可供查閱細部題型及示例。教材、音檔與題本需合法取得，初版不複製官方題目。不同地區或版本可能有不同施測方式，報名前仍需確認當地官方資訊。

900+ 是本職業的學習目標，必須由實際測驗結果確認，系統不依時數推算或顯示預測分數，也不把模考原始答對率直接當成 ETS 量尺分數。

## 估時的證據邊界

[Cambridge English：Guided learning hours](https://support.cambridgeenglish.org/hc/en-gb/articles/202838506-Guided-learning-hours) 提供從初學者至 CEFR 各級的引導式學習時數參考，並強調學習背景、強度、年齡與課外接觸等因素會影響實際時間。該資料衡量的是分級能力的引導式學習，不是逐項文法、獨立自學、TOEIC 得分或學得較慢族群的平均。

因此本專案**沒有把該表換算成 TOEIC 900 所需時數，也沒有宣稱每項技能時數源於研究平均**。它只支持「學習時數存在個體差異」這個編排提醒。

## 本專案的編輯估時

- 對象：非母語的在職成人，包含零基礎、需要較多練習與重複接觸的人。
- 用途：為技能樹分配保守的學習預算，協助拆解與持續記錄。
- 單元：本次沿用既有每項 8–20 小時預算以限制變更範圍，尚未按新版任務逐項重新估時；不應視為新版活動必須耗滿的最低時間。
- 組成：示範理解、引導練習、自主練習、跨日回想與檢討；不同活動的實際比例可調整。
- 拆分：按內容與成人使用情境安排練習；複習、泛聽泛讀及作品修訂分散在多週，避免一次連續耗滿單項時數。
- 總量：168 項、2,758 小時，是編排加總，含重複練習及診斷，不是最低門檻或能力保證。
- 尚待校準：教師審閱、試用者紀錄、每項實際耗時分布及長期學習成果。

教師與試用校準前，課程內容與先備仍是待驗證的教學方案。自我檢核中的 8/10 等門檻、字數和時長是專案自訂練習目標，不是 ETS 或 CEFR 官方通過標準；不同題組也不具有自動等值性。

## 命名與圖示

技能名稱、符文框架和 SVG 圖形為本專案原創，借用的是奇幻天賦樹的視覺語彙。圖示由 `scripts/build_curriculum.py` 呼叫 `scripts/skill_icons.py` 產生，並無使用影像生成 API 或遊戲素材。新版每項技能在 `scripts/curriculum_source.json` 的 `art` 明確指定圖樣與配色，圖樣及八組配色沿用 `scripts/skill_icons.py` 的既有 SVG 系統；例如聽辨用耳朵、回想用回轉箭頭、段落寫作用羽筆、進度回報用圖表、協商用圓桌。圖示標題同步使用新版技能名與主題。
