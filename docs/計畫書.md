# 符文之路：產品與開發計畫書

版本：0.1｜日期：2026-10-17｜狀態：可操作本機初版與後續規劃

## 一、目標與範圍

讓單一使用者用奇幻角色天賦樹管理學習：職業代表學習目標，技能代表明確的學習單元，1 點代表 1 小時實際投入。介面借鏡遊戲中的分支、連線、鎖定、滿點與詳情面板，使用原創名稱與圖示。

首職業定為 **Eng-TOEIC／英語行者**，先採傳統 TOEIC Listening & Reading 兩小時測驗作為目標，最終希望正式測驗達 900 分以上。英語日常交流、口說寫作與母語人士互動，之後另開 Eng- 開頭職業，避免混淆不同目標。

使用對象包含小學生；初版核心操作只需「選技能 → 看內容 → 學習 → 加一點」。不需註冊、登入、部署伺服器或學習複雜的角色配裝。

## 二、第一版的具體成果

| 項目 | 初版範圍 |
| --- | --- |
| 職業 | Eng-TOEIC，預留日語、素描及其他 Eng- 職業 |
| 技能 | 168 項，每項 8–20 小時，含實際主題、內容與自我檢核 |
| 圖示 | 168 個原創 SVG：分支主題圖樣、學習提示字與獨立銘文 |
| 技能操作 | 每次投入／收回 1 點，限制 0 到上限 |
| 先備 | 多先備全部滿點後解鎖，支援跨路線相依 |
| 退點 | 後續已有投入時，先退後續技能，防止進度失效 |
| 儲存 | 每次變更即寫入瀏覽器 localStorage |
| 備份 | JSON 匯出、匯入驗證及取代前確認 |
| 重置 | 確認後全職業歸零並儲存 |
| 導覽 | 六條路線、跨路線搜尋、技能樹與清單、先備跳轉 |
| 部署 | Python 標準函式庫啟動，無安裝第三方依賴 |

初版不包含課程影音、完整練習題庫、AI 家教、計時器、登入、多人、排行榜、付費、雲端同步或官方測驗成績認證。這些功能不影響本次本機單人需求。

## 三、六條天賦路線

| 路線 | 技能數 | 規劃時數 | 子路線 |
| --- | ---: | ---: | --- |
| 符文基礎 | 24 | 292 | 字母與拼讀、音標與發音、最初的詞語、句子啟程 |
| 語法鍛造 | 40 | 602 | 詞性與結構、時態與語氣、子句與假設、進階語法 |
| 詞彙秘庫 | 32 | 536 | 生活與旅途、職場與組織、商業與產業、記憶與語塊 |
| 聆聽迴廊 | 28 | 518 | 聲音解碼、照片與問答、對話探索、獨白探索 |
| 閱讀高塔 | 28 | 524 | 句子與填空、單篇文書、閱讀策略、多篇與速度 |

| 合計 | 168 | 2,758 | 詳細內容見技能目錄 |

字母和音標可分別啟程；後續技能採具體先備關係。沒有學習必要性的相鄰主題不互鎖，例如醫療詞彙不必先學住宅維修，閱讀廣告不必先讀完公告。英語聽讀本身有共通基礎，因此允許合理的跨路線先備。

時數只代表課程編排預算，各節點可包含多次短練習，不要求一次連續學滿。對小學生可將一小時分為數次，累計滿一小時再記 1 點；初版不記錄不足一小時的小數。

## 四、估時原則

沒有足以支持「非母語、學得較慢者學會每個文法項目的平均時數」的逐項可靠資料。因此逐項時數由課程編輯保守估計，不能標成統計平均。

每個節點的預算包括理解示範、引導練習、自主練習、跨日回想與錯誤修正。簡單單元約 8–12 小時，中度單元 12–18 小時，整合或反覆應用 18–20 小時。超過 20 小時的主題拆為多節點；例如 if 假設句拆成零／第一類、第二類、第三類、混合與 wish 四項。

全樹 2,758 小時是所有預算相加，包含重複檢討和複測，不能理解成每個人都必須完成才可考試，也不能當作 TOEIC 900 的能力對照表。以每週 10 小時計，整份預算約需 5.3 年；每週 20 小時約 2.7 年，僅供估算規劃量，並非推薦學習年限。先做診斷、選擇適合內容，再以實際表現調整。

滿點只是完成這個節點的記錄時數。自我檢核不理想時可持續練習；未來可加入額外複習紀錄，不以超過 20 點解決。已有基礎者目前可依過往投入逐點記錄，後續再評估診斷跳級。

## 五、介面與操作

桌面左側為職業、六路線與備份功能；中央呈現目前路線的四條子路線、徽章及相依連線；右側顯示技能說明與加退點。頁首顯示全職業累計時數、完成技能和可開始技能。

視覺採深森林綠、舊金、石刻與符文徽章，名稱偏奇幻但實際內容保持明白。每個徽章帶學習提示字，例如 A–Z、if、P3、75′。不使用 Diablo、D&D 或 Warcraft 的原圖、商標或音效。

手機將路線改成橫向導覽，技能樹可捲動，詳情移至下方；也能切換清單。提供鍵盤操作、可見焦點、文字狀態、跳至技能樹連結及減少動態效果設定。

關鍵情境：

1. 初次開啟為 0 點，字母與 KK 入門可開始。
2. 「初始字母之印」8/8 後可學「雙生字母契約」。
3. 進階技能灰色時仍能查看內容及先備，點先備按鈕可定位。
4. 點錯退一點；如已有後續進度，說明需先退哪些後續技能，不連帶清除。
5. 關閉後用相同來源重新開啟，保持先前點數。
6. 匯入前顯示備份摘要，確認後才取代；無效備份不影響原狀態。
7. 重置前顯示將歸零的時數與完成數，允許取消。
