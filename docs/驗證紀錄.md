## 自動測試

安裝開發依賴後執行 `node --test`：**44 項通過、0 項失敗**。涵蓋：

- 六分支、168 項技能、各節點 1–20 小時，168 個 SVG 檔案存在。
- 字母及 KK 入門可獨立開始，鎖定技能不可投入。
- 每次一點、滿點才解鎖、禁止超點及負數。
- 加退點不原地修改既有狀態。
- 後續已有投入時禁止退先備點數，退完後續即可繼續。
- 多先備必須全部滿點；不同詞彙主題不互相鎖定。
- 全樹可透過合法操作投入 2,758 點，再合法退回零。
- 拒絕循環相依、遺失先備、重複識別碼及超時技能。
- 儲存後重新建立儲存介面仍還原進度；重置後保持零。
- JSON 匯出匯入往返一致，拒絕不相容結構、職業或課程版本。
- 拒絕未知技能、小數、負值、字串、超上限及先備不完整的備份。
- 損毀或超大備份不覆蓋既有資料；原始損毀資料仍可保留。
- 瀏覽器儲存被拒絕、容量不足時回報錯誤。
- 匯入、重置及技能滿點時儲存失敗，提示不被成功訊息蓋掉；記憶體新進度與原始儲存值各自保留。
- 跨分頁 `clear()` 清除事件會被辨識，後續操作不恢復已清除的舊點數。
- 排除其他儲存空間與無關鍵事件，延遲事件以儲存空間當前值為準。
- 桌面資源的相對網址、版本參數、MIME 與根目錄首頁。
- 拒絕外部來源、帳密網址、跨目錄、反斜線、空字元與不支援的資源類型。
- 固定存檔位置在設定前先建立資料夾，退出時要求寫入尚未落盤的進度。
- 桌面隔離設定、權限拒絕、說明視窗與外部導覽限制。
- 首頁載入失敗會提示並退出，避免留下隱藏程式；說明載入失敗可單獨關閉並重試，提前關閉視窗不會再顯示錯誤或視窗。
- 兒童版操作說明完整且不引用外部腳本或樣式。
- 以真實 ASAR 驗證完整資源；故意排除說明檔時會讓驗證失敗。
- Mac 中文 ZIP 同時標記本機與中央目錄為 UTF-8，重跑不更動；非 UTF-8 檔名與截斷檔案不會被靜默修改。

## 本次審查修正

PR #1 的留言指出校驗清單會掃描整個 `release/`，把舊版本或這次未建置的套件一併列入，確認為實際問題。已改為由目前版本與指定平台決定檔名，並新增 5 項回歸測試；不刪除使用者留存的舊產物。

桌面版的 `loadURL` 拒絕原先未接住，首頁失敗可能留下隱藏視窗與啟動鎖；已補上失敗處理，首頁失敗結束程式，說明失敗僅關閉說明視窗。新增 3 項回歸測試。另將 Node.js 最低版本由 22.12 調至 22.13，與 pnpm 11.25 的要求一致。

發現儲存例外時，匯入、重置及滿點成功訊息會覆蓋失敗提示；已統一儲存結果與訊息來源。另發現 `localStorage.clear()` 的跨分頁事件被忽略，以及延遲事件會套用舊值；已補齊事件辨識並改讀目前儲存值。新增 7 項回歸測試，原 16 項測試也維持通過。

## 驗證限制

未實測所有 Safari、Firefox 或實體手機版本，也未完成兒童使用者試用、英語教師審閱與長期儲存耐久測試。儲存拒絕、容量不足、損毀及不相容備份等分支由自動測試覆蓋，未逐一以瀏覽器設定注入。未實測極短間隔的多分頁競爭寫入；目前採最後一次寫入為準，建議單分頁記錄。

Windows 10 實機首次啟動、原生檔案對話框與長期存檔尚未驗收；Mac 原生視窗流程也尚未完整實機驗收。桌面入口的設定與資源流程由介面替身測試覆蓋，不等同兩平台完整操作測試。兩個版本皆未做發行者簽章，Mac 未公證；下載後可能遭系統提示或阻擋，不能宣稱完全沒有首次開啟提示。

自我檢核只是文字指引；時數、能力與測驗得分的對應沒有經過實證驗證。本次完成的是本機可操作初版與課程規劃，不是完整教學平台。
