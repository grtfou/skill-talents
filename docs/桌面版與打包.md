# 桌面版與打包

版本：0.2.0｜日期：2026-10-17。

這份文件給維護、打包與分發程式的人。一般使用者請看[操作說明](操作說明.md)，不需要進行以下安裝步驟。

## 交付格式

| 對象 | 檔案 | 使用方式 |
| --- | --- | --- |
| Windows 10／11，64 位元 x64 | `release/SkillTalents-0.2.0-win-x64.zip` | 解壓縮整個資料夾，執行 `SkillTalents.exe` |
| Mac Intel，macOS 12 以上 | `release/SkillTalents-0.2.0-mac-x64.zip` | 解壓縮，將「符文之路.app」移至「應用程式」後開啟 |
| 檔案完整性 | `release/SHA256SUMS.txt` | 供維護者核對下載是否完整，不是發行者簽章 |

Windows ZIP 是免安裝的完整資料夾，不是單一可獨立搬走的 exe；裡面的 DLL、資源與語言檔必須一起保留。使用者不需管理員權限即可執行正常功能。

目前優先交付 x64。另提供 `package:win32` 建置入口，但本次未產出或驗證 Windows 32 位元版；Mac Apple Silicon 也不是這次的目標，不能把 x64 壓縮檔當作原生 arm64 版本。

Electron 把 Chromium 與 Node.js 一起放入應用程式，因此使用者不需額外安裝 Python、Node.js、WebView2 或其他執行環境；代價是壓縮檔約百餘 MB。[Electron 官方介紹](https://www.electronjs.org/docs/latest/)

## 使用方式

應用程式直接開啟自己的視窗，不啟動 Python、不占用 4173 連接埠，也不必另外開啟瀏覽器。程式與說明書都在套件內，沒有網路仍可使用。程式內的「說明 → 操作說明」與「如何遊玩 → 完整操作說明」都能開啟兒童版說明。

本機資料位置固定為：

- Windows：`%APPDATA%\SkillTalents`。
- macOS：`~/Library/Application Support/SkillTalents`。
- 程式內部來源固定為 `skill-talents://app`，沿用相同的職業 ID、儲存鍵與課程版本。

不要為了更新或重裝程式而刪除上述資料夾。移動 .app 或 Windows 免安裝資料夾不會改變資料位置；不同電腦使用者帳號則有各自的進度。仍應定期用 JSON 匯出備份，避免磁碟故障或清理程式資料造成遺失。

舊的 Python 網頁版與桌面版不是同一份儲存空間。請在舊版「匯出旅程」，再到桌面版「匯入備份」。沒有自動讀取原瀏覽器個人資料或搬移進度。

## 開發與建置

僅維護者需要 Node.js 22.13 以上（建議 24）及 pnpm 11.25。一般使用者拿到 ZIP 後不需要這些工具。

```sh
# 第一次取得原始碼後，依鎖定檔安裝開發工具
pnpm install --frozen-lockfile

# 執行規則、儲存、桌面入口及打包回歸測試
pnpm test

# 開發時下載主機的 Electron 執行環境，再開啟桌面視窗
pnpm run setup:desktop
pnpm start

# 產生操作說明；也會在每次打包前自動執行
pnpm run build:help

# Mac Intel ZIP：需在 macOS 上建置
pnpm run package:mac

# Windows x64 ZIP：可在 Windows 或 macOS 上建置
pnpm run package:win

# 在 macOS 一次產生上述兩個版本
pnpm run package:all

# 重新檢查本機兩個產物是否有完整說明、課程和圖示
pnpm run verify:desktop

# 如另有 Windows 32 位元需求
pnpm run package:win32
```

Electron 43 的 npm 套件提供獨立的 `install.js` 下載入口；開發啟動前需執行 `setup:desktop`。正式打包由 electron-builder 自行取得對應平台的 Electron，因此不需先安裝另一個平台的開發執行環境。

依賴版本固定於 `package.json` 與 `pnpm-lock.yaml`。目前 Electron 為 43.8.0、electron-builder 為 26.15.3；使用 Electron 43 是為保留 macOS 12 相容性。Electron 44 已移除 macOS 12 支援；後續更新需重新評估最低系統版本，不能只改 plist 宣稱支援較舊系統。[Electron 44 發行說明](https://www.electronjs.org/blog/electron-44-0)

`package-desktop.mjs` 僅建立本機產物，明確設定 `publish: never`，不會自動上傳 GitHub 或發行到公開網址。`release/`、套件下載快取與 `node_modules/` 不納入 Git。

`SHA256SUMS.txt` 每次只列出目前版本、本次指定平台的 ZIP。例如 `package:win` 只列 Windows x64，`package:all` 只列 Mac Intel 與 Windows x64。目錄中的舊版本或其他平台檔案會保留，但不納入本次校驗清單；如缺少必要產物，建置會回報失敗並保留原清單。

每次建置都會讀取實際 `app.asar`，確認首頁、操作說明、程式模組、課程及 168 個圖示完整，並比對來源與版本；缺少說明時直接讓建置失敗。Mac ZIP 使用系統 `ditto` 保留執行權限與 Framework 符號連結，再由 `zip-utf8.mjs` 確認原始檔名為 UTF-8，補齊本機標頭與中央目錄的 UTF-8 標記；不依賴解壓縮工具猜測中文編碼。此流程只支援一般未加密 ZIP，超過 ZIP64 門檻時會明確失敗。

輸出目錄另外提供可獨立開啟的 `release/操作說明.html`，方便分發給不想先開程式的家長或老師。

若只想開啟舊網頁版供開發測試，可執行 `python3 start.py`，或已裝開發工具時執行 `pnpm run start:web`；這是選用的備用入口。

## 操作說明維護

`docs/操作說明.md` 是唯一文字來源，`scripts/build-help.mjs` 產生 `app/help.html`。後者包含自己的樣式，不引用外部字型或服務，能直接離線開啟，也能從桌面程式開啟。

請先修改 Markdown，再執行 `build:help`；不要只修改產生的 HTML，否則下一次建置會被覆寫。README 為四步驟入門摘要，技術安裝資訊集中在本文件。

## 簽章與分發限制

本次 ZIP **未做發行者程式碼簽章，也未做 Apple 公證**。Mac Gatekeeper 或 Windows SmartScreen 可能顯示安全提示或阻擋，不能宣稱下載到任何電腦都完全沒有提示。兒童遇到提示時，說明書請他們停下來找大人協助確認來源；不附移除隔離標記或停用系統保護的腳本。

要面向大量一般使用者公開分發，需要另行準備：

- Mac：Developer ID Application 憑證、Apple 公證驗證方式，開啟 hardened runtime 與公證，簽章後重新測試 ZIP。
- Windows：有效發行者簽章方式，將 `signExecutable` 改回啟用並配置簽章；簽章有助確認發行者，但不保證 SmartScreen 一定沒有提示。

目前設定刻意不搜尋或使用電腦中既有的簽章身分。簽章憑證與密碼不可放進 Git 或壓縮檔。[electron-builder Mac 簽章說明](https://www.electron.build/v26/docs/mac/)、[Windows 簽章選項](https://www.electron.build/v26/docs/win/)

## 驗證邊界

原始碼有桌面入口與資源協定測試，涵蓋固定儲存位置、獨立說明視窗、視窗隔離、資源 MIME 與禁止外部導覽。這些測試使用 Electron 介面替身，不等同每個作業系統的實機視窗驗收。

另檢查實際壓縮檔、執行檔架構與內含資源。Windows 10 實機的首次啟動、存檔及檔案對話框仍需測試；本次環境是 Intel Mac。詳細結果記於[驗證紀錄](驗證紀錄.md)。
